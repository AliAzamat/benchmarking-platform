# AI Agent Evaluation & Benchmarking Platform

The capstone of the journey. Bring it all together into a real platform: a LangGraph agent runner that executes tool-using agents across a suite of diverse tasks, bounded-concurrency batch evaluation of thousands of runs, a Postgres-backed leaderboard with rankings, a Redis-fanned-out WebSocket gateway that streams every run to a React dashboard as it completes, head-to-head agent comparison and a prompt-tuning experiment harness for rapid iteration, metrics and observability for latency and cost, and a Docker Compose deployment ready for AWS. Both batch and real-time evaluation, thousands of runs in parallel.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- Python
- FastAPI
- LangGraph
- OpenAI
- Redis
- WebSockets
- PostgreSQL
- React
